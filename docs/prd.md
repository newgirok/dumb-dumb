## 서비스 한 줄 정의

**숲친구** — 유저가 의인화된 동물 캐릭터를 조종하여 로우폴리 3D 숲 씬을 누비고 탐험하는 **오픈월드 소셜 서비스**.

- **비주얼**: 베이크드 로우폴리(Low-Poly) 3D 숲 씬 + 3인칭 추적 카메라, 네이처 펑크(숲) 테마의 의인화된 동물 캐릭터
- **지원 환경**: PC 웹 브라우저 + 모바일 앱 하이브리드

---

## Part 1. 핵심 제품 명세

### 월드 구성

- **메인 월드 = 베이크드 로우폴리 3D 숲 씬** (단일 Three.js WebGL 캔버스). 오솔길·집·창고·나무·바위·간판·랜드마크는 **씬 지오메트리에 구워진 정적/인스턴스 에셋**이다. 월드 좌표계는 씬 로컬 좌표를 쓴다.
- **화면 5시(우하단) 나침반형 GIS 미니맵 = 독립 Mapbox GL 캔버스.** 유저의 실제 GPS 위치를 실지형 지도 위에 표시하는 보조 뷰다.
- **화면 중심 주체는 캐릭터(3D 씬)**, 미니맵은 보조 뷰다.

### 플레이 모드

| 기기 | 이동 조작 | 미니맵 |
|---|---|---|
| PC 웹 | 키보드 WASD | 실제 GPS 위치 표시 (가능 시) |
| 모바일 | 가상 조이스틱 | 실제 GPS 위치 표시 |

- 씬 내 캐릭터 이동은 WASD/가상 조이스틱이 구동한다.
- 모바일 GPS는 5시 미니맵의 실제 위치 표시에만 쓰이고 씬 이동을 직접 구동하지 않는다.

### 카메라 규칙

- **메인 씬**: 3인칭 추적 카메라 — 캐릭터를 뒤에서 따라가며 이동을 담는다.
- **5시 GIS 미니맵**: 유저 위치를 중심에 고정 추적하고, 드래그·줌 조작을 차단한다 (`dragPan disable`).
- 모바일 자이로 센서: 15도 이하 변위 무시, 초과 시 0.2초 Lerp 적용.

### 가시거리(숲 안개, Fog of War) 등급

숲 속을 걷는 동물의 시야는 원래 넓지 않다 — 짙은 나무 그늘과 안개가 시야를 가린다는 세계관을 그대로 게임 메카닉으로 가져온다. 씬의 **뷰 디스턴스(거리 안개)** 등급으로 구현한다.

| 등급 | 반경 | 구분 |
|---|---|---|
| 기본 (무료) | 20~30m | 최초 가입 유저 |
| 2단계 | 100m | 가시거리 라이선스 구매 |
| 3단계 | 300m | 가시거리 라이선스 구매 |

## Part 2. 기술 스택

| 레이어 | 기술 | 비고 |
|---|---|---|
| 코어 프레임워크 | Next.js 15 (App Router, CSR, Turbopack) | |
| 로컬 개발 환경 | Docker Compose + WATCHPACK_POLLING | WSL/Windows 파일 감지 호환 |
| 3D 엔진 | Three.js | 베이크드 로우폴리 숲 씬 + GLB 동물 캐릭터 렌더링 |
| 렌더링 파이프라인 | WebGL Context Sharing | 메인 씬 단일 WebGL 캔버스, 모바일 60fps |
| GIS 미니맵 | Mapbox GL JS v3 | 독립 경량 캔버스, 실제 GPS 위치 표시 전용. 무료 티어 |
| 프론트엔드 배포 | Vercel | Edge Network CDN |
| API 서버 | NestJS 11 (`apps/api`) | 자체 호스팅 |
| 데이터베이스 | PostgreSQL + PostGIS (자체 호스팅, 단일 공유 DB) | 공간 연산 내장 |
| 실시간 소켓 | socket.io (NestJS WebSocket 게이트웨이) | 섹터 단위 위치·채팅 브로드캐스트 |
| 인증 | 자체 JWT + bcrypt, 카카오/구글 OAuth | 이메일+비밀번호 + 소셜 로그인 |
| 공간 음성 | LiveKit Cloud | 매니지드 SFU, 무료 티어 |

월 고정비: 자체 호스팅 기준(DB/API 서버 호스팅 + Mapbox·LiveKit·Vercel 무료 티어~소액). 상세는 [아키텍처 개요 — 비용 목표](./architecture/overview.md#비용-목표) 참고.

## Part 3. 수익 모델 (Business Model)

### 인앱 결제 — 원화 직행

```
[원화 결제] → [카카오페이 / 토스페이 / 신용카드] → 즉시 확정 지급
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  상품 1: 3D 동물 캐릭터 (2,200원)      상품 2: 가시거리 라이선스 (정가)
  → AI 조합 100% 유니크 발급            → 기능성 시야 확장 권한
```

- 확률형 아이템 없음, 100% 확정 발급
- 유저 간 NFT/P2P 거래 없음, 순수 인앱 귀속
- 10개 패키지 (19,000원) = 동물 캐릭터 10종 + 가시거리 2단계 번들

### B2B 공간 스폰서십 (CPT 모델)

- 숲 씬에 배치된 랜드마크(그루터기 간판, 버섯집, 속이 빈 큰 나무 등)에 브랜드 텍스처를 매핑하고, 5시 미니맵에는 좌표 마커로 표시한다 (기간 고정제 정가 판매).
- 무료 유저 시야 경계(35m 지점)에 스폰서 랜드마크 실루엣 노출 → 결제 유도

## Part 4. 데이터 모델 핵심

### characters 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `serial_number` | VARCHAR(32) UNIQUE | 유저 노출용 시리얼 (`Dog #3,491`) |
| `owner_id` | UUID FK | `users` 소유자 |
| `appearance_hash` | CHAR(64) UNIQUE | 외형 조합 SHA-256 해시 (겹침 방지) |
| `created_at` | TIMESTAMPTZ | 결제 완료 시각 |

### sponsor_buildings 테이블

> 테이블명은 설계 규약상 `sponsor_buildings`지만, 실제로는 도시 건물이 아니라 숲 속 랜드마크(그루터기·바위·옹달샘 등에 입힌 브랜드 텍스처)를 저장한다. `geom`은 5시 GIS 미니맵의 좌표 마커 레이어를 받친다.

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `geom` | GEOMETRY(Point, 4326) | 랜드마크 미니맵 좌표 (GiST 인덱스 필수) |
| `texture_url` | TEXT | 브랜드 로고 URL |
| `advertiser_id` | UUID FK | 광고주(`users`, `role: advertiser`) 계정 |
| `starts_at` / `ends_at` | TIMESTAMPTZ | 광고 집행 기간 |

## Part 5. 유저 이벤트 흐름

```
[최초 접속]
  → 이메일+비밀번호 회원가입 또는 소셜 OAuth (카카오·구글) → 약관 동의
  → 기본 라이선스(가시거리 1단계) 회원가입 트랜잭션에서 자동 귀속

[로그인]
  → 자체 JWT 자가 검증 (15분 Access + 30일 Refresh)
  → 3D 숲 씬 로딩 (Three.js WebGL 캔버스)
  → 안전 경고 팝업 (3초 Dim)

[인게임 루프]
  → WASD/조이스틱 씬 이동(3인칭 추적 카메라) → 씬 오솔길 위 이동
  → 5시 GIS 미니맵에 실제 GPS 위치 표시
  → socket.io 섹터 위치 브로드캐스트(씬 로컬 좌표)
  → 가시거리 경계 씬 뷰 디스턴스(거리 안개) 렌더링
  → B2B 스폰서 랜드마크 감지 (PostGIS ST_DWithin) → 노출 카운팅

[상점 트랜잭션]
  → 원화 결제 → 주문 UUID 멱등 처리 → 캐릭터/라이선스 발급
  → 실패 시 자동 취소 롤백

[로그아웃]
  → Three.js dispose() → GPS 세션 파기 → 토큰 폐기
```

## Part 6. UI/UX 원칙

- 미니맵이 아닌 **캐릭터(나의 동물 분신)** 가 화면의 중심 주체
- 3D 공간 광고만 허용, 2D 팝업 배너 전면 금지
- 랜드마크 클릭 시 팝업 없음 — 캐릭터 절레절레 No-Action 애니메이션으로 대응

### 비주얼 레이어 구분

| 레이어 | 디자인 방향 | 비고 |
|---|---|---|
| **랜딩 페이지 (`/`)** | 숲과 동물 세계관을 담은 AI 생성 스크롤 시네마틱 · 미니멀 화이트 헤더 | 서비스 소개 · 전환 유도 |
| **인게임 · 상점 UI (`/dashboard`, `/store` 등)** | 숲친구 스타일 — Nunito 폰트, oklch 자연 색상 팔레트, 물리적 무게감 있는 라운드 카드 | 플레이 몰입감 유지 |

## Part 7. 멀티플레이어 음성 & 채팅

- **공간 음성**: LiveKit Cloud SFU, 거리 기반 볼륨 감쇠 + 3D 오디오 패닝 (씬 로컬 좌표 기준)
- **근접 반경**: 30m 이내 진입 시 룸 자동 연결, 40m 이탈 시 즉시 파기
- **동시 구독 제한**: 거리 기준 Top-8 트랙만 구독 (Subscription Capping)
- **채팅**: socket.io 무상태 소켓, DB 저장 없음, 7초 후 자동 페이드아웃
