## 서비스 한 줄 정의

**숲친구** — 유저가 의인화된 동물 캐릭터를 조종하여 실제 지형 위에 펼쳐진 숲을 누비고 탐험하는 **오픈월드 소셜 서비스**.

- **비주얼**: 45도 고정 쿼터뷰 + 로우폴리(Low-Poly) 스타일, 네이처 펑크(숲) 테마의 의인화된 동물 캐릭터
- **지원 환경**: PC 웹 브라우저 + 모바일 앱 하이브리드

## Part 1. 핵심 제품 명세

### 플레이 모드

| 기기 | 모드 | 조작 |
|---|---|---|
| PC 웹 | 가짜 이동 전용 | 키보드 WASD |
| 모바일 | 실제 이동 (GPS) / 가짜 이동 토글 | GPS 추적 / 가상 조이스틱 |

### 카메라 규칙

- Pitch 45~50도 고정, Bearing 45도 고정 (X자 격자 시야)
- 유저의 드래그·줌 조작 전면 차단 (`Camera Hijack`)
- 모바일 자이로 센서: 15도 이하 변위 무시, 초과 시 0.2초 Lerp 적용

### 가시거리(숲 안개, Fog of War) 등급

숲 속을 걷는 동물의 시야는 원래 넓지 않다 — 짙은 나무 그늘과 안개가 시야를 가린다는 세계관을 그대로 게임 메카닉으로 가져온다.

| 등급 | 반경 | 구분 |
|---|---|---|
| 기본 (무료) | 20~30m | 최초 가입 유저 |
| 2단계 | 100m | 가시거리 라이선스 구매 |
| 3단계 | 300m | 가시거리 라이선스 구매 |

## Part 3. 수익 모델 (Business Model)

### 인앱 결제 — 원화 직행

```
[원화 결제] → [카카오페이 / 토스페이 / 신용카드] → 즉시 확정 지급
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  상품 1: 3D 동물 캐릭터 (2,200원)      상품 2: 가시거리 라이선스 (정가)
  → AI 조합 100% 유니크 발급            → 기능성 시야 확장 권한
```

- 확률형 아이템 없음, 100% 확정 발급
- 유저 간 NFT/P2P 거래 없음, 순수 인앱 귀속
- 10개 패키지 (19,000원) = 동물 캐릭터 10종 + 가시거리 2단계 번들

### B2B 공간 스폰서십 (CPT 모델)

- 실제 지형 좌표 위에 놓인 랜드마크(그루터기 간판, 버섯집, 속이 빈 큰 나무 등)에 브랜드 텍스처를 매핑 (기간 고정제 정가 판매)
- 무료 유저 시야 경계(35m 지점)에 스폰서 랜드마크 실루엣 노출 → 결제 유도

## Part 4. 데이터 모델 핵심

### characters 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `serial_number` | VARCHAR(32) UNIQUE | 유저 노출용 시리얼 (`Dog #3,491`) |
| `owner_id` | UUID FK | Supabase Auth 유저 |
| `appearance_hash` | CHAR(64) UNIQUE | 외형 조합 SHA-256 해시 (겹침 방지) |
| `created_at` | TIMESTAMPTZ | 결제 완료 시각 |

### sponsor_buildings 테이블

> 테이블명은 초기 설계 당시 그대로 유지하지만, 실제로는 도시 건물이 아니라 숲 속 랜드마크(그루터기·바위·옹달샘 등에 입힌 브랜드 텍스처)를 저장한다.

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `geom` | GEOMETRY(Point, 4326) | 랜드마크 위치 (GiST 인덱스 필수) |
| `texture_url` | TEXT | 브랜드 로고 URL |
| `advertiser_id` | UUID FK | 광고주 계정 |
| `starts_at` / `ends_at` | TIMESTAMPTZ | 광고 집행 기간 |

## Part 5. 유저 이벤트 흐름

```
[최초 접속]
  → 이메일 OTP 인증 또는 소셜 OAuth (카카오·구글) → 약관 동의
  → 기본 동물 캐릭터 + 가시거리 1단계 자동 귀속

[로그인]
  → JWT 자가 검증 (15분 Access + 14일 Refresh)
  → 3D 숲 월드 로딩 (WebGL 컨텍스트 믹싱)
  → 안전 경고 팝업 (3초 Dim)

[인게임 루프]
  → 조이스틱/WASD 이동 → 오솔길 스냅 → Realtime 위치 브로드캐스트
  → 가시거리 경계 숲 안개 렌더링
  → B2B 스폰서 랜드마크 감지 (PostGIS ST_DWithin) → 노출 카운팅

[상점 트랜잭션]
  → 원화 결제 → 멱등성 키 검증 → 캐릭터/라이선스 발급
  → 실패 시 자동 환불 롤백

[로그아웃]
  → Three.js dispose() → GPS 세션 파기 → Auth 토큰 폐기
```

## Part 6. UI/UX 원칙

- 지도가 아닌 **캐릭터(나의 동물 분신)** 가 화면의 중심 주체
- 3D 공간 광고만 허용, 2D 팝업 배너 전면 금지
- 랜드마크 클릭 시 팝업 없음 — 캐릭터 절레절레 No-Action 애니메이션으로 대응

### 비주얼 레이어 구분

| 레이어 | 디자인 방향 | 비고 |
|---|---|---|
| **랜딩 페이지 (`/`)** | 숲과 동물 세계관을 담은 AI 생성 스크롤 시네마틱 · 미니멀 화이트 헤더 | 서비스 소개 · 전환 유도 |
| **인게임 · 상점 UI (`/world`, `/store` 등)** | 숲친구 스타일 — Nunito 폰트, oklch 자연 색상 팔레트, 물리적 무게감 있는 라운드 카드 | 플레이 몰입감 유지 |

## Part 7. 멀티플레이어 음성 & 채팅

- **공간 음성**: LiveKit Cloud SFU, 거리 기반 볼륨 감쇠 + 3D 오디오 패닝
- **근접 반경**: 30m 이내 진입 시 룸 자동 연결, 40m 이탈 시 즉시 파기
- **동시 구독 제한**: 거리 기준 Top-8 트랙만 구독 (Subscription Capping)
- **채팅**: Supabase Realtime 무상태 소켓, DB 저장 없음, 7초 후 자동 페이드아웃
