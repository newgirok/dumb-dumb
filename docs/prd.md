# 제품 요구사항 문서 (PRD)

> 목적: 1인 개발 + AI 개발 툴 활용 프로토타입 빌드용 마스터 명세서

---

## 서비스 한 줄 정의

**Dumb Dumb** — 유저가 반려동물을 목줄로 데리고 다니는 반려인 3D 아바타를 조종해 3D 공간을 느긋하게 누비고, 다른 유저와 우연히 마주치며 커뮤니티를 형성하는 **3D 소셜 서비스**. 선택 페이지 제목과 브라우저 탭 제목("플레이 · Dumb Dumb"처럼 페이지 이름 뒤)에 이 이름을 쓴다(`app/page.tsx`, `app/layout.tsx`).

- **비주얼**: 회화풍 로우폴리(Low-Poly) 3D — 채도 높은 파란 하늘과 흰 뭉게구름 아래 흙길·나무 울타리·들꽃·목장이 이어지는 시골 풍경. 3인칭 추적 카메라로 걷는 플레이 씬, 내 위치 주변 실제 길을 같은 화풍으로 까는 내 주변(베타), 로그인 유저용 맵(Mapbox 실지형 지도 위 3D 캐릭터, 쿼터뷰 고정 카메라 — 예정)으로 구성한다
- **지원 환경**: PC·모바일 웹 브라우저

## Part 1. 핵심 제품 명세

### 화면 구성

| 화면 | 경로 | 구성 | 좌표계 |
|---|---|---|---|
| **플레이 씬** | `/play` | 씬 전용 단일 Three.js WebGL 캔버스에 그리는 베이크드 로우폴리 씬(`features/play`). 지형·바다·하늘 돔·집·창고·가로등·나무 등은 정적/인스턴스 메시로, 캐릭터·생물은 스킨드 메시로 ref-assets 에셋을 배치한다. 로그인 없이 공개하며, 같은 방(최대 20명) 다른 방문자의 캐릭터가 익명 소켓으로 함께 보이고, 가까이 마주친 사람과는 서로 받아들이면 1:1로 글을 주고받는다(만남 대화) | 씬 로컬 미터 좌표 |
| **내 주변 (베타)** | `/nearby` | 내 위치 주변 실제 길(OpenStreetMap 벡터 타일)을 플레이 씬과 같은 렌더링·화풍으로 깐 공간(`features/nearby`). 걷는 만큼 256m 구역을 이어 깔아 끝이 없고, 반경 200m 안 가까운 19명의 캐릭터가 실제 자리에 익명으로 보인다. 건물·소품·물은 2단계에서 붙인다 | GPS 위치를 0.001° 격자에 맞춘 원점 기준 미터(1m = 1m). 다른 사람과는 위경도로 주고받는다 |
| **맵 (예정)** | `/map` | Mapbox GL Standard 실지형 지도(3D 건물 내장) 위에 Three.js 캐릭터를 커스텀 레이어로 얹는 로그인 유저용 멀티플레이 화면 | 위경도 (EPSG:4326) |

- 루트(`/`)는 게임 타이틀 화면으로 꾸민 선택 페이지이고, 공개 진입점이다. 여름 오후 풍경 일러스트 위에 제목 "Dumb Dumb"과 목적지 버튼 3개(플레이 · 내 주변(베타) · 에셋 미리보기 개발용)를 세로로 쌓아 둔다. `/asset-viewer`는 ref-assets 캐릭터·소품의 크기·본·애니메이션·인스턴스·LOD 규격을 눈으로 확인하는 개발용 에셋 미리보기다. 모든 페이지는 로그인 없이 열린다.
- **펼침 지도**(Paper Map, `components/map/paper-map.tsx`)는 플레이 씬과 내 주변에서 우상단 지도 버튼이나 M 키로 펼치는 종이 지도 모양의 독립 Mapbox GL 캔버스다. 북쪽이 위인 평면 지도에 플레이 씬은 유저의 실제 GPS 위치를, 내 주변은 캐릭터 자리와 화면이 보는 방향을 '나'로 표시하는 보조 뷰이고, GPS 상태(찾는 중·흐림·권한 거부 등)를 쪽지·도장·정확도 원으로 보여 준다. 펼쳐 둔 동안은 캐릭터 직접 조작을 멈춘다(내 주변 휴대폰의 GPS 걷기는 계속된다).
- 세 화면 모두 **화면 중심 주체는 캐릭터**다.
- 플레이 씬·내 주변·에셋 미리보기가 쓰는 3D 에셋과 플레이 씬의 오디오·폰트는 지금 참조용 ref-assets(`public/ref-assets/`)이며, [로드맵](./roadmap.md) P2-5에서 모두 자체 에셋으로 바꾼다.

### 캐릭터

- 내 캐릭터는 반려동물을 목줄로 데리고 걷는 반려인이다. 반려동물은 반려인 곁에서 걸음을 맞춰 따라오고, 목줄이 반려인 손과 반려동물 목을 잇는다
- 반려인의 첫 기본 모습은 모자 없는 검은 단발에 흰 티셔츠·파란 반바지를 입은 아이다. 외형은 파츠 조합(피부·헤어·헤어 색·상의·상의 색·하의·하의 색·신발·액세서리)으로 그리고, 발급받은 아바타 외형(Part 3)을 그대로 입는다. 앞으로 아이부터 어른까지 여러 모습의 에셋 중에서 고를 수 있게 한다
- 반려동물은 강아지·고양이부터 목장·숲·야생 동물까지 종이 다양하고, 앞으로 여러 종의 에셋 중에서 고를 수 있게 한다. 첫 출시 종과 마릿수는 로드맵 P2-5에서 정한다
- 같은 방·같은 동네의 다른 방문자에게도 반려인과 반려동물이 함께 보인다

### 플레이 모드

| 화면 | 기기 | 이동 조작 | GPS 사용 |
|---|---|---|---|
| 플레이 씬 | PC 웹 | WASD·방향키, 마우스 왼쪽 버튼 가상 조이스틱, 스페이스·오른쪽 클릭 점프 | 펼침 지도 '나' 표시 |
| 플레이 씬 | 모바일 웹 | 터치 드래그 가상 조이스틱 | 펼침 지도 '나' 표시 |
| 내 주변 | PC 웹 | 플레이 씬과 같다 | 시작 위치 조회 (위치를 받을 때까지 대기 화면에서 기다린다) |
| 내 주변 | 모바일 웹 | 실제 GPS 위치까지 걸어간다 (±50m 안 위치만 따르고, 1.5m 안이면 서고, 150m 넘게 튀면 곧장 옮긴다) | 캐릭터 위치 구동 |
| 맵 (예정) | PC 웹 | WASD·방향키 (남북 3m/s, 동서 약 2.4m/s) | 시작 위치 조회 |
| 맵 (예정) | 모바일 웹 | 실제 GPS 이동 | 캐릭터 위치 구동 |

- 플레이 씬의 GPS는 펼침 지도의 '나' 표시에만 쓰이고 씬 이동을 구동하지 않는다. 사이트 위치 권한이 이미 허용돼 있으면 씬을 열 때 바로 찾고, 아니면 지도를 처음 펼칠 때 권한을 묻는다.
- 내 주변은 위치를 받을 때까지 대기 화면에서 기다렸다가 시작한다 — ±50m 안 위치가 오면 바로 시작하고, 그보다 흐리면 6초 더 다듬어 그 사이 가장 나은 위치로 이 근처에서 시작한다(위치를 하나도 못 받으면 넘어가지 않는다). PC는 시작한 자리에서 키보드로 걷고(흐린 위치로 시작했어도 나중에 옮기지 않는다), 모바일에서는 ±50m 안 GPS 위치가 캐릭터를 끌고 간다.
- 단축키: 플레이 씬과 내 주변에서 M은 펼침 지도 펼치기·접기, Esc는 접기다. 플레이 씬의 Ctrl+M은 사운드 버튼과 같은 소리 켜기·끄기이고, E는 머리 위에 말풍선 표시가 뜬 사람(또는 [말 걸기]가 켜진 카드 상대)에게 바로 말 걸기다. 물리 키 기준이라 한글 입력 상태에서도 동작한다.
- 맵은 모바일에서 실제 GPS 위치가 곧 캐릭터 위치이며, 새 위치는 15m 이내 도로에 스냅한다.

### 카메라 규칙

- **플레이 씬**: 3인칭 추적 카메라 — 시선 목표점(발 위 1.1m) 중심 반경 5.836m·앙각 9.866°에서 캐릭터를 뒤따른다. 구도는 화면 비율을 따른다(반응형 구도). 16:9 이상은 이 구도(세로 화각 45°)를 그대로 쓰고, 세로로 긴 화면일수록(9:19.5까지) 화각을 66°까지 넓히고 조금 물러나 높이 올라가 앞길이 보이게 한다. 유저가 카메라를 직접 돌리는 입력은 받지 않는다. 내 주변도 같은 카메라로 걷는다 ([ADR 006](./adr/006-quarter-view-camera-lock.md))
- **맵 (예정)**: 쿼터뷰 고정 카메라 — pitch 45°·bearing 45°를 고정하고 이동할 때마다 지도 중심을 캐릭터로 맞춘다. 줌(14~20)만 허용한다
- **펼침 지도**: 북쪽이 위인 평면 지도다. 펼칠 때 '나'(플레이 씬은 유저 GPS 위치, 내 주변은 캐릭터)에게 맞추고, 끌기와 확대·축소(줌 11~18.5)만 허용하며 회전·기울이기는 막는다. 플레이 씬에서 위치가 ±150m보다 흐리면 정확도 원 전체가 들어오게 물러난다

### 가시거리(Fog of War) 등급

캐릭터 중심 반경 밖을 가리는 가시거리(Fog of War)는 탐험 긴장감과 수익 모델을 잇는 핵심 메카닉이다. 반경은 유저별 가시거리 라이선스로 관리하고, 라이선스 구매로 넓힌다.

| 등급 | 반경 | 구분 |
|---|---|---|
| 기본 (무료) | 25m | 회원가입 시 자동 귀속 |
| 2단계 | 100m | 가시거리 100m 라이선스 구매 |
| 3단계 | 300m | 가시거리 300m 라이선스 구매 |

반경 값은 `user_licenses.visibility_radius_m`에 저장한다. 씬 렌더링에 반경을 적용하는 작업은 Phase 4에서 진행한다.

## Part 3. 수익 모델 (Business Model)

### 인앱 결제 — 원화 직행

```
[원화 결제] → [카카오페이 / 토스페이 / 신용카드] → 즉시 확정 지급
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  상품 1: 3D 아바타 외형권 (2,200원)    상품 2: 가시거리 라이선스
  → 외형 조합 100% 유니크 발급          → 100m 4,900원 / 300m 9,900원
```

- 확률형 아이템 없음, 100% 확정 발급
- 유저 간 NFT/P2P 거래 없음, 순수 인앱 귀속
- 아바타 10종 묶음 (19,800원) = 3D 아바타 외형 10종
- 아바타 외형은 외형 파라미터 조합 + 난수 시드로 만들고, 조합 해시(`appearance_hash`)의 UNIQUE 제약으로 중복을 막는다. 생성형 AI 외형 생성은 같은 해시 구조 위에 붙인다
- 주문·발급·반경 조회는 API 서버가 처리하고, 상품을 고르고 주문하는 상점 화면(`/store`)은 예정이다

### B2B 공간 스폰서십 (CPT 모델)

- 씬에 배치한 스폰서 랜드마크에 브랜드 텍스처를 매핑하고, 펼침 지도에는 좌표 마커로 표시한다 (기간 고정제 정가 판매)
- 무료 유저 시야 경계(35m 지점)에 스폰서 랜드마크 실루엣을 노출해 결제를 유도한다
- 스폰서 랜드마크 테이블·공간 인덱스·기간 스케줄러는 DB에 있고, 씬 배치·펼침 지도 좌표 마커·노출 감지는 Phase 4에서 붙인다

## Part 4. 데이터 모델 핵심

### characters 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `serial_number` | VARCHAR(32) UNIQUE | 유저 노출용 시리얼 (`OW-00000001`) |
| `owner_id` | UUID FK | `users` 소유자 |
| `appearance_hash` | CHAR(64) UNIQUE | 외형 조합 SHA-256 해시 (겹침 방지) |
| `appearance_data` | JSONB | 외형 파라미터 조합 |
| `order_id` / `order_seq` | UUID FK / INTEGER | 발급 주문과 주문 내 순번 (`(order_id, order_seq)` UNIQUE로 중복 발급 차단) |
| `created_at` | TIMESTAMPTZ | 발급 시각 |

### sponsor_buildings 테이블

스폰서 랜드마크(브랜드 텍스처를 입힐 씬 오브젝트)의 좌표·텍스처·집행 기간을 저장한다.

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `geom` | GEOMETRY(Point, 4326) | 랜드마크 좌표 (GiST 인덱스) |
| `texture_url` / `default_texture_url` | TEXT | 브랜드 텍스처 URL / 비활성 기간 기본 텍스처 URL |
| `advertiser_id` | UUID FK | 광고주(`users`, `role: advertiser`) 계정 |
| `is_active` | BOOLEAN | 집행 중 여부 (pg_cron이 매일 갱신) |
| `starts_at` / `ends_at` | TIMESTAMPTZ | 광고 집행 기간 |

## Part 5. 유저 이벤트 흐름

```
[선택 페이지 — 공개 진입 (/)]
  → 타이틀 화면의 플레이(/play) · 내 주변(/nearby) · 에셋 미리보기(/asset-viewer, 개발용) 버튼 중 하나를 눌러 들어간다

[플레이 씬 (/play)]
  → 로딩 화면(스피너·안내 한 줄)이 스피너가 한 바퀴(1초) 이상 돈 뒤 0.75초에 걸쳐 사라지고, 그 뒤 인트로 전환(4초)과 카메라 돌리(6초)가 동시에 시작되고, 1.5초 뒤부터 조작할 수 있다
  → WASD·방향키·마우스/터치 조이스틱·게임패드 이동, 점프 (3인칭 추적 카메라, 화면 비율에 맞춘 반응형 구도)
  → 우상단 버튼 4개 — 소리 켜기·끄기(Ctrl+M) · 옷 색 바꾸기 · 지도 펼치기(M) · 말 걸기 받기 켜기·끄기
  → 펼침 지도에 실제 GPS 위치('나')를 표시한다 (지도가 화면에 있는 동안 — 접을 때는 배경이 다 걷힐 때까지 — 캐릭터 조작을 멈추고, M·Esc로는 언제든, ×·배경 클릭으로는 다 펼친 뒤에 접는다)
  → 로그인 없음. 익명 소켓으로 방(최대 20명)을 배정받아 다른 방문자의 캐릭터가 위치·방향·모션·옷 색 그대로 보인다
    (이름표 없음, 서버에 닿지 못하면 혼자)
  → 만남 대화: 상대 캐릭터를 눌러 머리 위 카드의 [말 걸기](4m 안, PC는 가까이 선 사람에게 E로 바로) → 상대 화면에 요청 카드(15초) → 상대가 좋아요를 누르면
    두 사람만 보는 대화 창이 열린다 → ×·멀어짐·3분 동안 말 없음·상대가 떠남으로 끝난다 (Part 7)

[내 주변 — 베타 (/nearby)]
  → 위치를 받을 때까지 대기 화면에서 기다린다 (±50m 안이면 바로, 그보다 흐리면 6초 더 다듬어 이 근처에서 시작한다. 권한 거부·https 아님·미지원이면 넘어가지 않고 상태별 안내를 보여 준다)
  → 주변 실제 길을 플레이 씬 화풍으로 깔고, 걷는 만큼 앞쪽을 이어 깐다 (1m = 1m, 도로 폭은 도로명 대로·로·길)
  → PC는 플레이 씬과 같은 조작, 모바일은 ±50m 안 GPS 위치까지 걸어간다 (더 흐리면 멈춰 두고 위쪽 알림으로 알린다)
  → 우상단 지도 버튼이나 M 키로 펼침 지도를 펼치면 캐릭터 자리와 화면이 보는 방향이 '나'로 보인다
  → 반경 200m 안 가까운 19명의 캐릭터가 실제 자리에 보인다 (익명, 채팅·이름표 없음)

[회원가입·로그인 (/login, 화면 예정)]
  → 이메일+비밀번호 또는 소셜 OAuth (카카오·구글)
  → 기본 가시거리 라이선스(25m)를 회원가입 트랜잭션에서 생성
  → 자체 JWT (15분 Access + 30일 Refresh, Refresh는 httpOnly 쿠키)

[맵 루프 (/map, 화면 예정)]
  → GPS 현재 위치를 받을 때까지 기다렸다가 그 자리에서 시작 (정해 둔 기본 좌표로 시작하지 않는다)
  → PC WASD·방향키 / 모바일 실제 GPS 이동 → 15m 이내 도로 스냅
  → 200ms마다 위치 전송 → 서버가 속도 검증·섹터 판정 후 섹터별 묶음 방송 (위경도)
  → 50m 이동마다 450m 밖 피어 오브젝트 정리

[상점 트랜잭션 (/store, 화면 예정)]
  → 주문서 발행(PENDING) → PG 승인 웹훅(서명 검증·금액 대조) → 결제 확정(PAID) (PG 결제창 연동은 예정)
  → 지급 워커가 아바타·라이선스 발급 (외형 충돌은 다시 추첨하고 누적 8회면 수동 확인, 그 밖의 실패는 다음 주기에 재시도, 주문·순번 단위 중복 차단)

[로그아웃]
  → token_version 증가로 모든 기기의 리프레시 토큰 폐기 → 리프레시 쿠키 삭제
```

## Part 6. UI/UX 원칙

- 지도가 아닌 **캐릭터(나의 분신)** 가 화면의 중심 주체 — 펼침 지도는 필요할 때 펼쳐 보는 보조 뷰다
- 3D 공간 광고만 허용, 2D 팝업 배너 전면 금지
- 랜드마크 클릭 시 팝업 없음 — 캐릭터 절레절레 No-Action 애니메이션으로 대응한다 (스폰서 랜드마크와 함께 Phase 4)

### 비주얼 레이어 구분

| 레이어 | 디자인 방향 | 비고 |
|---|---|---|
| **선택 페이지 (`/`)** | 게임 타이틀 화면 — 여름 오후 풍경 일러스트 위에 Luckiest Guy 제목 "Dumb Dumb"과 세로로 쌓은 목적지 버튼 3개(크림 `#f9efdc` + 하드 그림자 `#716c66`, 번갈아 살짝 기울임, 아이콘·이름만). 휴대폰 가로처럼 낮은 화면도 스크롤 없이 한 화면에 담는다 | 공개 진입점 |
| **플레이 씬·내 주변 (`/play`, `/nearby`)** | 씬 HUD — 우상단에 10° 기울인 크림(`#f9efdc`) 아이콘 버튼 + 하드 그림자(`#716c66`). 버튼은 플레이 씬이 소리·옷 색·지도·말 걸기 받기 4개, 내 주변이 지도 1개다. 로딩 화면은 스피너와 안내 한 줄인 로더이고, 내 주변은 위치를 받을 때까지 같은 로더로 기다리며 걷는 중에는 위쪽 알림 한 줄을 띄운다. 펼침 지도는 같은 색 언어의 종이 지도에 Stylish 글씨. 만남 대화의 말풍선 표시·말 걸기 카드·요청 카드·대화 창·머리 위 말풍선도 같은 크림 + 하드 그림자에 Pretendard 글씨(제목은 Stylish) | 로그인 없이 공개 |
| **인게임 · 상점 UI (`/map`, `/store` 등, 예정)** | Nunito 폰트, 검은 배경 위 반투명 라운드 카드, oklch 색상 토큰(`--color-grass` 등) | 로그인 유저 |
| **마케팅 웹사이트** | 서비스 소개·전환 유도 | SaaS 완성 이후 별도 앱으로 제작 |

## Part 7. 멀티플레이어 대화

유저끼리는 글(메시지)로만 대화하고, 대화 글은 어디에도 저장하지 않는다. 플레이 씬은 가까이 마주친 두 사람의 만남 대화를, 맵(예정)은 섹터 채팅을 쓴다. 내 주변(베타)은 서로의 캐릭터만 보여 주고, 만남 대화는 [로드맵](./roadmap.md) P2-6에서 붙인다.

- **만남 대화 (플레이 씬)**: 가까이 마주친 사람과 서로 받아들여 1:1로 글을 주고받는다. 로그인 없는 익명 대화라 이름·프로필 없이 캐릭터만 보인다
  - 화면에 보이는 상대 캐릭터를 누르면(클릭·탭) 그 사람 머리 위에 카드가 뜨고, 카드의 [말 걸기]로 건다(로블록스 아바타 메뉴·클럽 펭귄 플레이어 카드 방식 — 카드에는 나중에 인사·친구·차단 버튼이 붙는다). [말 걸기]는 4m 안(야외에서 평소 목소리로 대화가 들리는 거리)에서 켜지고 4.5m 밖에서 꺼진다. 화면 밖 사람은 누를 수 없다. 4m 안에 2초 머문, 화면에 보이는 가장 가까운 사람 머리 위에는 작은 말풍선 표시가 떠 누를 수 있는 사람임을 알리고, PC는 E 키로 그 사람에게 바로 건다. 건 요청을 기다리던 중에 상대가 4.5m 밖으로 가면 요청도 거둔다. 걸면 상대 화면에 "옆에서 말을 걸었어요" 카드(좋아요·다음에)가 15초 동안 뜨고, 상대가 받아들이면 두 사람만 보는 대화 창이 열린다. 서로 동시에 걸면 곧바로 열린다
  - 대화 창에는 빠른 문구(안녕하세요·반가워요·어디 가는 길이에요?·좋은 하루 보내요)와 입력칸(200자)이 있고, 보낸 글은 두 사람 머리 위 말풍선으로도 7초 동안 보인다. 링크는 보낼 수 없다
  - ×를 누르거나, 10m 넘게 10초 멀어지거나, 3분 동안 글이 없거나, 상대가 떠나면 끝나고 끝난 까닭을 한 줄로 알린다
  - 거절되거나 15초 안에 답이 없으면 건 사람에게는 "지금은 바쁜가 봐요"로만 알리고(거절인지 바쁜지 가리지 않는다) 5분 동안 그 사람에게 다시 걸 수 없다. 우상단 말 걸기 받기 버튼을 끄면 오는 요청을 카드 없이 거절한다(브라우저에 기억)
  - 익명 대화는 시험 단계다. 공개 출시 전에 로그인·신고·차단과 이용 연령을 갖추고 대화 저장 여부를 정한다(랜덤 채팅 관련 규정 검토, [로드맵](./roadmap.md) P5-3)
- **섹터 채팅 (맵, 예정)**: socket.io 무상태 섹터 방송(200자), DB 저장 없음. 방송은 실시간 서버의 `/sector` 게이트웨이가 하고, 입력 UI와 말풍선 표시(7초 후 자동 페이드아웃)는 화면과 함께 붙인다
- **만남 인사 (예정)**: 스치면 반려동물끼리 먼저 알아채고 반가워한다. 정해진 반응이라 수락 없이 보인다. 한 반려인이 인사를 청하고 상대 반려인이 받아들이면 반려동물끼리 인사하고 두 반려인의 만남 대화가 열린다. 거절은 글 대신 반려동물이 아쉬워하는 동작으로만 알린다. 적용 화면·알아채는 거리·인사 연출은 결정 필요
