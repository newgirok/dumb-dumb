# 제품 요구사항 문서 (PRD)

> 목적: 1인 개발 + AI 개발 툴 활용 프로토타입 빌드용 마스터 명세서

---

## 서비스 한 줄 정의

**오픈월드** — 유저가 3D 아바타를 조종해 로우폴리 3D 월드를 누비고, 다른 유저와 우연히 마주치며 커뮤니티를 형성하는 **오픈월드 소셜 서비스**.

- **비주얼**: 로우폴리(Low-Poly) 3D. 공개 진입점인 루트 3D 씬(3인칭 추적 카메라)과 로그인 유저용 대시보드 월드(Mapbox 실지형 지도 위 3D 캐릭터, 쿼터뷰 고정 카메라)로 구성한다
- **지원 환경**: PC·모바일 웹 브라우저

## Part 1. 핵심 제품 명세

### 월드 구성

| 월드 | 경로 | 구성 | 좌표계 |
|---|---|---|---|
| **루트 3D 씬** | `/` | 씬 전용 단일 Three.js WebGL 캔버스에 그리는 베이크드 로우폴리 씬(`app/summer-afternoon`). 지형·바다·하늘 돔·집·창고·가로등·나무 등은 정적/인스턴스 메시로, 캐릭터·생물은 스킨드 메시로 ref-assets 에셋을 배치한다. 로그인·서버 연결 없이 공개한다 | 씬 로컬 미터 좌표 |
| **대시보드 월드** | `/dashboard` | Mapbox GL Standard 실지형 지도(3D 건물 내장) 위에 Three.js 캐릭터를 커스텀 레이어로 얹은 멀티플레이 월드(`components/world/WorldCanvas.tsx`) | 위경도 (EPSG:4326) |

- **화면 5시(우하단) 나침반형 GIS 미니맵**은 루트 3D 씬에만 뜨는 독립 Mapbox GL 캔버스다. 유저의 실제 GPS 위치를 실지형 지도 위에 표시하는 보조 뷰다.
- 두 월드 모두 **화면 중심 주체는 캐릭터**다.
- 루트 3D 씬의 에셋은 참조용 ref-assets이며, 자체 제작 에셋으로 교체할 때 `/preview`에서 크기·본·애니메이션·인스턴스 규격을 대조한다.

### 플레이 모드

| 월드 | 기기 | 이동 조작 | GPS 사용 |
|---|---|---|---|
| 루트 3D 씬 | PC 웹 | WASD·방향키, 마우스 왼쪽 버튼 가상 조이스틱, 스페이스·오른쪽 클릭 점프 | 5시 미니맵 위치 표시 |
| 루트 3D 씬 | 모바일 웹 | 터치 드래그 가상 조이스틱 | 5시 미니맵 위치 표시 |
| 대시보드 월드 | PC 웹 | WASD·방향키 (남북 3m/s, 동서 약 2.4m/s) | 시작 위치 조회 |
| 대시보드 월드 | 모바일 웹 | 실제 GPS 이동 | 캐릭터 위치 구동 |

- 루트 3D 씬의 GPS는 미니맵 표시에만 쓰이고 씬 이동을 구동하지 않는다.
- 대시보드 월드는 모바일에서 실제 GPS 위치가 곧 캐릭터 위치이며, 새 위치는 15m 이내 도로에 스냅한다.

### 카메라 규칙

- **루트 3D 씬**: 3인칭 추적 카메라 — 시선 목표점(발 위 1.2m) 중심 반경 5.9m·앙각 9.866°에서 캐릭터를 뒤따른다. 유저가 카메라를 직접 돌리는 입력은 받지 않는다 ([ADR 007](./adr/007-quarter-view-camera-lock.md))
- **대시보드 월드**: 쿼터뷰 고정 카메라 — pitch 45°·bearing 45°를 고정하고 이동할 때마다 지도 중심을 캐릭터로 맞춘다. 줌(14~20)만 허용한다
- **5시 GIS 미니맵**: 유저 위치를 중심에 고정 추적하고, 모든 조작을 차단한다(`interactive: false`, 줌 16 고정)

### 가시거리(Fog of War) 등급

캐릭터 중심 반경 밖을 가리는 가시거리(Fog of War)는 탐험 긴장감과 수익 모델을 잇는 핵심 메카닉이다. 반경은 유저별 가시거리 라이선스로 관리하고, 라이선스 구매로 넓힌다.

| 등급 | 반경 | 구분 |
|---|---|---|
| 기본 (무료) | 25m | 회원가입 시 자동 귀속 |
| 2단계 | 100m | 가시거리 100m 라이선스 구매 |
| 3단계 | 300m | 가시거리 300m 라이선스 구매 |

반경 값은 `user_licenses.visibility_radius_m`에 저장한다. 월드 렌더링에 반경을 적용하는 작업은 Phase 5에서 진행한다.

## Part 3. 수익 모델 (Business Model)

### 인앱 결제 — 원화 직행

```
[원화 결제] → [카카오페이 / 토스페이 / 신용카드] → 즉시 확정 지급
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  상품 1: 3D 아바타 외형권 (2,200원)    상품 2: 가시거리 라이선스
  → 외형 조합 100% 유니크 발급          → 100m 4,900원 / 300m 9,900원
```

- 확률형 아이템 없음, 100% 확정 발급
- 유저 간 NFT/P2P 거래 없음, 순수 인앱 귀속
- 아바타 10종 묶음 (19,800원) = 3D 아바타 외형 10종
- 아바타 외형은 외형 파라미터 조합 + 난수 시드로 만들고, 조합 해시(`appearance_hash`)의 UNIQUE 제약으로 중복을 막는다. 생성형 AI 외형 생성은 같은 해시 구조 위에 붙인다

### B2B 공간 스폰서십 (CPT 모델)

- 월드에 배치한 스폰서 랜드마크에 브랜드 텍스처를 매핑하고, 5시 미니맵에는 좌표 마커로 표시한다 (기간 고정제 정가 판매)
- 무료 유저 시야 경계(35m 지점)에 스폰서 랜드마크 실루엣을 노출해 결제를 유도한다
- 스폰서 랜드마크 테이블·공간 인덱스·기간 스케줄러는 DB에 있고, 월드 배치·미니맵 마커·노출 감지는 Phase 5에서 붙인다

## Part 4. 데이터 모델 핵심

### characters 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `serial_number` | VARCHAR(32) UNIQUE | 유저 노출용 시리얼 (`OW-00000001`) |
| `owner_id` | UUID FK | `users` 소유자 |
| `appearance_hash` | CHAR(64) UNIQUE | 외형 조합 SHA-256 해시 (겹침 방지) |
| `appearance_data` | JSONB | 외형 파라미터 조합 |
| `order_id` / `order_seq` | UUID FK / INTEGER | 발급 주문과 주문 내 순번 (`(order_id, order_seq)` UNIQUE로 중복 발급 차단) |
| `created_at` | TIMESTAMPTZ | 발급 시각 |

### sponsor_buildings 테이블

스폰서 랜드마크(브랜드 텍스처를 입힐 월드 오브젝트)의 좌표·텍스처·집행 기간을 저장한다.

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `geom` | GEOMETRY(Point, 4326) | 랜드마크 좌표 (GiST 인덱스) |
| `texture_url` / `default_texture_url` | TEXT | 브랜드 텍스처 URL / 비활성 기간 기본 텍스처 URL |
| `advertiser_id` | UUID FK | 광고주(`users`, `role: advertiser`) 계정 |
| `is_active` | BOOLEAN | 집행 중 여부 (pg_cron이 매일 갱신) |
| `starts_at` / `ends_at` | TIMESTAMPTZ | 광고 집행 기간 |

## Part 5. 유저 이벤트 흐름

```
[루트 3D 씬 — 공개 진입 (/)]
  → 로딩 화면(타이틀 + 스피너) → 인트로 전환(4초)과 카메라 돌리(6초)가 동시에 시작되고, 그 순간부터 조작할 수 있다
  → WASD·방향키·가상 조이스틱 이동, 점프 (3인칭 추적 카메라)
  → 5시 GIS 미니맵에 실제 GPS 위치 표시
  → UFO 10m 이내 접근 시 secret 모달, 우상단 비밀 카운터 n/5
  → 로그인·서버 연결 없음

[회원가입·로그인 (/login)]
  → 이메일+비밀번호 또는 소셜 OAuth (카카오·구글)
  → 기본 가시거리 라이선스(25m)를 회원가입 트랜잭션에서 생성
  → 자체 JWT (15분 Access + 30일 Refresh, Refresh는 httpOnly 쿠키)

[대시보드 월드 루프 (/dashboard)]
  → GPS 현재 위치에서 시작 (실패 시 서울시청 부근)
  → PC WASD·방향키 / 모바일 실제 GPS 이동 → 15m 이내 도로 스냅
  → 200ms마다 위치 전송 → 서버가 속도 검증·섹터 판정 후 섹터별 묶음 방송 (위경도)
  → 섹터 음성 룸 자동 접속, 40m 이내 가까운 8명만 오디오 구독 (마이크 송출 UI는 예정이라 현재 송출하는 유저는 없다)
  → 50m 이동마다 450m 밖 피어 오브젝트 정리

[상점 트랜잭션 (/store)]
  → 주문서 발행(PENDING) → PG 승인 웹훅(서명 검증·금액 대조) → 결제 확정(PAID) (PG 결제창 연동은 예정)
  → 지급 워커가 아바타·라이선스 발급 (외형 충돌은 다시 추첨하고 누적 8회면 수동 확인, 그 밖의 실패는 다음 주기에 재시도, 주문·순번 단위 중복 차단)

[로그아웃]
  → token_version 증가로 모든 기기의 리프레시 토큰 폐기 → 리프레시 쿠키 삭제
```

## Part 6. UI/UX 원칙

- 미니맵이 아닌 **캐릭터(나의 분신)** 가 화면의 중심 주체
- 3D 공간 광고만 허용, 2D 팝업 배너 전면 금지
- 랜드마크 클릭 시 팝업 없음 — 캐릭터 절레절레 No-Action 애니메이션으로 대응한다 (스폰서 랜드마크와 함께 Phase 5)

### 비주얼 레이어 구분

| 레이어 | 디자인 방향 | 비고 |
|---|---|---|
| **루트 3D 씬 (`/`)** | 씬 HUD — Stylish 폰트, 크림(`#f9efdc`) 버튼 + 하드 그림자(`#716c66`), 10° 기울인 버튼과 가운데 정보 모달 | 공개 진입점 |
| **인게임 · 상점 UI (`/dashboard`, `/store` 등)** | Nunito 폰트, 검은 배경 위 반투명 라운드 카드, oklch 색상 토큰(`--color-grass` 등) | 로그인 유저 |
| **마케팅 웹사이트** | 서비스 소개·전환 유도 | SaaS 완성 이후 별도 앱으로 제작 |

## Part 7. 멀티플레이어 음성 & 채팅

대시보드 월드의 기능이다.

- **공간 음성**: LiveKit Cloud SFU. 섹터마다 음성 룸(`voice-{sectorId}`)을 두고, 섹터에 들어가면 해당 룸에 자동 접속한다
- **근접 구독**: 40m 이내 피어 중 거리 기준 Top-8 트랙만 구독한다 (Subscription Capping)
- **3D 오디오**: HRTF 패닝 + 거리 감쇠 — 30m까지 최대 볼륨, 40m에서 무음 (위경도 거리·방위 기준)
- **마이크 송신**: 옵트인(`enableMic`) — 권한 거부 시 수신 전용. 송신 활성화 UI는 예정이다
- **채팅**: socket.io 무상태 섹터 방송(200자), DB 저장 없음. 입력 UI와 말풍선 표시(7초 후 자동 페이드아웃)는 예정이다
