# ADR 006: 가시거리 안개를 BM과 연동하는 설계

**상태:** Accepted

## 결정

**가시거리 안개(Fog of War)**를 단순한 UX 연출이 아니라 수익 모델(BM)과 직접 연동된 핵심 게임 메카닉으로 설계한다. 안개는 지도 위 레이어가 아니라 **3D 씬의 뷰 디스턴스(거리 안개)**로 구현한다.

- 무료 유저: 반경 25m까지만 선명, 외곽은 짙은 거리 안개로 페이드
- 가시거리 라이선스 구매 시: 반경 100m 또는 300m까지 안개 해제

## 배경

일반적인 게임 BM의 두 가지 전형적 문제를 피해야 했다.

1. **능력치 차등 아이템**: "강한 캐릭터 = 돈 쓴 유저" 구조는 공정성 논란과 게임법 규제 대상
2. **보상 파밍 시스템**: 미션·퀘스트·보상 루프는 구현 복잡도가 높고 사행성 심의 리스크

## 근거

가시거리 안개 연동은 다음 세 목표를 동시에 달성한다.

| 목표 | 내용 |
|---|---|
| 초기 렌더링 비용 방어 | 뷰 디스턴스를 25m로 제한해 무료 유저가 그리는 씬 지오메트리·드로우콜 범위를 좁게 유지 |
| 유기적 결제 전환 유도 | 안개 경계면에 스폰서 랜드마크 실루엣·보물상자 Glow를 노출하여 구매 욕구 자연 자극 |
| 광고 구좌 연동 | 무료 유저의 좁은 시야로 인해 스폰서 랜드마크가 안개 너머에 있어 → 구매 시 랜드마크가 시원하게 펼쳐지는 "결제 만족도" 연출 |

## 현재 구현

| 영역 | 상태 |
|---|---|
| 판매 | `license_100m`(4,900원)·`license_300m`(9,900원)을 원화 정가로 판매한다([ADR 004](./004-direct-krw-payment.md)) |
| 저장 | `user_licenses.visibility_radius_m`(기본 25). 발급 워커가 보유값과 상품 반경 중 큰 값으로 올린다(`GREATEST`) |
| 조회 | `GET /api/me/license`가 `visibilityRadiusM`을 돌려주고(행이 없으면 25), 상점(`/store`)이 표시한다. 가시거리는 JWT에 담지 않는다 |
| 렌더링 | 두 월드 모두 가시거리 반경을 렌더링에 적용하지 않는다. `lib/three/fog.ts`(CSS radial-gradient 비네트, `--fog-radius`)는 마운트되는 곳이 없다 |

루트 3D 씬의 램프 셰이더에는 카메라 거리 40~300m에서 채도를 0.3 이하로 낮추고 명도를 0.6 쪽으로 모으는 고정 대기 원근 페이드가 있으나, 가시거리 라이선스와 무관하다.

## 렌더링 적용 계획

```
[무료 유저 시야: 반경 25m]
  → 거리 안개(포그) 셰이더로 외곽 페이드 (반경 작음)
  → 35m 지점 스폰서 랜드마크 실루엣 + Glow 노출 (구매 유도)

[가시거리 라이선스 발급 후]
  → 라이선스 반경(visibility_radius_m)만큼 뷰 디스턴스(포그 far) 확장 연출
  → 스폰서 랜드마크 입체 간판 텍스처 풀 렌더링
```

## 분리 원칙

- **아바타 외형 ≠ 성능**: 아바타 구매는 시각 요소만, 가시거리에 영향 없음
- **가시거리 = 기능 라이선스**: 아바타와 독립 판매, 능력치가 아닌 기능 확장권
- **B2B 광고 ≠ 파밍 보상**: 스폰서 랜드마크는 구경 대상일 뿐, 클릭 보상/파밍 요소 없음
