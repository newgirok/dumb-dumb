# 비즈니스 규칙

핵심 도메인 규칙. 제품 전체 요구사항은 [PRD](../prd.md), 개발 로드맵은 [로드맵](../roadmap.md)을 참고하세요.

## 1. 결제 규칙

### 상품 구조

| 상품 | 금액 | 내용 | 특성 |
|---|---|---|---|
| 아바타 외형권 | 2,200원 | AI 조합 유니크 3D 로우폴리 동물 캐릭터 1종 | 100% 확정 발급 |
| 가시거리 100m 해제권 | 정가 | 캐릭터 중심 가시거리 안개 반경 100m 확장 | 기능 라이선스 |
| 가시거리 300m 해제권 | 정가 | 캐릭터 중심 가시거리 안개 반경 300m 확장 | 기능 라이선스 |
| 10개 번들 | 19,000원 | 아바타 10종 + 가시거리 100m 라이선스 무료 | 번들 할인 아님, 부가 제공 |

### 결제 불변 규칙

- 확률형 아이템 없음 — 모든 결제는 100% 확정 발급
- 중간 가상 화폐 없음 — 원화 직행 결제만 허용
- 아바타 외형은 가시거리(성능)에 영향 없음 — 순수 시각 요소
- 유저 간 아바타 거래/환전 없음 — 순수 인앱 귀속 소유형

### 결제 처리 규칙

- 주문 UUID(멱등성 키) 기반 중복 결제 방어 필수
- 캐릭터 발급 실패 시 PG사 자동 취소 API 호출 → 원화 환불 3초 이내
- CS 로그: 롤백 발생 시 [user_id, order_id, amount, pg_approval_number, error] 원자적 적재

## 2. 가시거리 규칙

### 등급 정의

| 등급 | 반경 | 획득 방법 |
|---|---|---|
| 기본 (1단계) | 20~30m | 회원가입 시 자동 귀속 |
| 2단계 | 100m | 가시거리 라이선스 구매 |
| 3단계 | 300m | 가시거리 라이선스 구매 |

### 안개 경계 광고 규칙

- 무료 유저 시야 경계선 바로 바깥(35m 지점)에 스폰서 랜드마크 실루엣 + Glow 효과 노출
- 결제 완료 0.1초 이내 CSS 안개 반경 즉시 확장 연출
- 가시거리 등급은 JWT Payload에 인코딩하여 Stateless 검증 (매 요청마다 DB 조회 금지)

## 3. 이동 제한 규칙

### 가짜 이동 (시뮬레이션 모드)

- 무료 유저: 당일 기준점에서 반경 1km 이내로 가짜 이동 제한
- 가시거리 라이선스 구매 시 1km 반경 락 해제
- 경계 도달 시 화면 중앙에 "이동 제한 반경 도달" 알림 페이드인

### 속도 검증

- 클라이언트: 직전 좌표와 비교하여 시속 30km 초과 패킷은 백엔드 미전송 (1차 방어)
- 백엔드: 10회 중 1회 샘플링 재검증 (2차 방어)
- 이상 패턴 감지 시 해당 유저 지도 렌더링 10분 동결

### GPS 오솔길 스냅

- 반경 15m 이내 가장 가까운 오솔길 중심선으로 강제 정렬
- 나무·바위 등 지형지물 폴리곤 내부 진입 차단
- 시속 8km(동물의 보통 걸음)를 초과하는 좌표 점프는 오솔길 라인 따라 Tweening으로 흡수

## 4. B2B 광고 규칙

### CPT(기간 고정제) 모델 고정

- CPC(클릭당 과금) / CPA(행동당 과금) 정산 방식 완전 배제
- 기간 고정 정가 구좌 판매만 허용 (예: 특정 랜드마크 1개월 독점 = 정가)

### 유효 노출 카운팅

- 유저 쿼터뷰 뷰포트 내 스폰서 랜드마크 바운딩 박스가 **1초 이상 완전히 진입** 시에만 DB 기록
- 0.1초 미만 스쳐 지나간 경우 카운팅 제외

### 광고 자동화 스케줄러

- `pg_cron`: 매일 0시 KST 기준으로 `starts_at == today` 구좌 활성화, `ends_at == yesterday` 구좌 비활성화
- 비활성화 시 텍스처 URL을 기본 숲 테마 나무 텍스처로 자동 원복

### 광고 형태 제한

- 3D 공간 내 로우폴리 입체 간판·랜드마크 표면 그래픽만 허용
- 2D 웹 팝업 배너·텍스트 팝업 전면 금지
- 랜드마크 클릭 시 팝업 호출 금지 (캐릭터 절레절레 No-Action 애니메이션으로 대체)

## 5. 멀티플레이어 규칙

### 음성 옵트인

- 유저가 명시적으로 음성 모드 활성화할 때만 LiveKit 룸 조인
- 마이크 권한 거부 시 수신(듣기)만 활성화, 송신 비활성화

### 채팅 규칙

- 모든 채팅 메시지는 DB 영구 저장 금지 (무상태 휘발성)
- 7초 후 말풍선 + 채팅 로그에서 자동 페이드아웃
- 도배 방지: 0.5초 메시지 발송 디바운스 락

### 안전 규칙

- 앱 구동 시 화면 주시 위험 경고 팝업 3초 강제 노출 (면책 팝업)
- 심야 시간대(23:00~05:00) 실제 이동 모드 자동 잠금
