# 비즈니스 규칙

핵심 도메인 규칙. 제품 전체 요구사항은 [PRD](../prd.md), 개발 로드맵은 [로드맵](../roadmap.md)을 참고하세요. 규칙 중 아직 구현되지 않은 항목은 **(예정)** 으로 표시한다.

## 1. 결제 규칙

### 상품 구조

| 상품 (`product_type`) | 금액 | 내용 | 특성 |
|---|---|---|---|
| 3D 아바타 외형권 (`character`) | 2,200원 | 외형 조합 유니크 3D 아바타 1종 | 100% 확정 발급 |
| 가시거리 100m (`license_100m`) | 4,900원 | 가시거리 라이선스 반경을 100m로 확장 | 기능 라이선스 |
| 가시거리 300m (`license_300m`) | 9,900원 | 가시거리 라이선스 반경을 300m로 확장 | 기능 라이선스 |
| 아바타 10종 묶음 (`bundle_10`) | 19,800원 | 유니크 3D 아바타 10종 | 묶음 발급 |

### 결제 불변 규칙

- 확률형 아이템 없음 — 모든 결제는 100% 확정 발급
- 중간 가상 화폐 없음 — 원화 직행 결제만 허용 (주문 하나가 곧 상품 하나)
- 아바타 외형은 가시거리(성능)에 영향 없음 — 순수 시각 요소
- 유저 간 아바타 거래/환전 없음 — 순수 인앱 귀속 소유형

### 결제 처리 규칙

- 주문 UUID(멱등성 키) 기반 중복 결제 방어 — 이미 `PAID`인 주문의 웹훅은 다시 적용하지 않고, PG 승인번호는 UNIQUE(`orders_pg_approval_uniq`)로 한 번만 기록한다
- 결제 웹훅은 주문 상태만 `PAID`로 바꾸고, 발급은 지급 워커가 따로 처리한다 — `PAID`·미지급 주문을 `FOR UPDATE SKIP LOCKED`로 집어 발급한다. 외형 해시가 겹치면 다시 추첨하며, 그 누적 횟수(`fulfill_attempts`)가 8에 닿은 주문은 워커 대상에서 빠져 수동 확인한다. 그 밖의 실패는 다음 주기(2초)에 다시 시도한다
- 아바타는 주문·순번(`order_id`, `order_seq`) UNIQUE 제약으로 한 번만 발급된다
- **(예정)** 재시도 한도를 넘긴 주문의 PG 자동 취소·환불(`REFUNDED`)과 CS 로그 [user_id, order_id, amount, pg_approval_number, error] 적재

## 2. 가시거리 규칙

### 등급 정의

| 등급 | 반경 | 획득 방법 |
|---|---|---|
| 기본 (1단계) | 25m | 회원가입 트랜잭션에서 자동 생성 |
| 2단계 | 100m | 가시거리 100m 라이선스 구매 |
| 3단계 | 300m | 가시거리 300m 라이선스 구매 |

### 반경 관리

- 반경은 `user_licenses.visibility_radius_m`에 저장한다. 라이선스를 발급할 때 현재 값과 구매 반경 중 큰 값으로 갱신해(`GREATEST`) 반경이 줄어들지 않는다
- API 서버 `GET /me/license`가 반경을 돌려준다(라이선스 행이 없으면 25m로 응답)
- **(예정)** 상점 화면에 반경을 표시한다
- **(예정, Phase 4)** 반경을 씬 렌더링(Fog of War)에 적용한다

### 안개 경계 광고 규칙 (예정, Phase 4)

- 무료 유저 가시거리 경계선 바로 바깥(35m 지점)에 스폰서 랜드마크 실루엣 + Glow 효과 노출
- 결제 완료 0.1초 이내 가시거리 반경 즉시 확장 연출

## 3. 이동 규칙

### 플레이 씬 (`/play`)

- PC는 WASD·방향키로 이동하고, 마우스 왼쪽 버튼을 누르는 동안 화면 고정점 기준 가상 조이스틱으로 커서 방향으로 이동한다. 스페이스·오른쪽 클릭(0.5초 미만)은 점프다
- 모바일은 처음 누른 자리 기준 터치 조이스틱으로 이동하고, 짧게 탭하면 점프한다. 게임패드(왼쪽 스틱·A 버튼)도 쓸 수 있다
- 이동은 관성이 있다 — 약 0.5초에 걸쳐 최고 속도 약 3.75m/s에 이르고, 손을 떼면 약 0.7m 미끄러져 선다. 3인칭 추적 카메라가 캐릭터를 따라간다
- 카메라 구도는 화면 비율을 따른다(반응형 구도) — 16:9 이상은 세로 화각 45° 구도 그대로, 세로로 긴 화면일수록(9:19.5까지) 화각을 66°까지 넓히고 조금 물러나 높이 올라가 앞길이 보이게 한다. 창 크기·회전으로 비율이 달라지면 부드럽게 따라간다. 마우스 조이스틱 고정점은 구도에 맞춰 캐릭터 발끝을 따라가고, 최대 세기 거리는 화면 짧은 변의 0.23배(90~200px)다
- 캐릭터는 캡슐로 충돌 메시(`collider.bin`)와 부딪친다 — 벽을 따라 미끄러지고, 낮은 턱만 넘고, 난간에서는 떨어진다
- GPS는 펼침 지도의 '나' 표시에만 쓰인다. 사이트 위치 권한이 이미 허용돼 있으면 씬을 열 때 바로 찾고, 아니면 지도를 처음 펼칠 때 권한을 묻는다
- 우상단 지도 버튼이나 M 키(Ctrl·Alt·Cmd 없이)로 펼침 지도를 펼치고 접으며, Esc는 접기만 한다. Ctrl+M은 사운드 버튼과 같은 소리 켜기·끄기다. E는 머리 위에 말 걸기 버튼이 뜬 사람에게 말을 건다(펼침 지도가 펼쳐져 있거나 입력칸에 쓰는 중이면 받지 않는다). 단축키는 물리 키 기준이라 한글 입력 상태에서도 동작하고(키 반복은 무시), 씬이 준비된 뒤부터 받는다
- 펼침 지도가 화면에 있는 동안은 캐릭터 조작을 끄고, 접을 때는 다 접혀 배경(dim)까지 걷힌 뒤에 다시 켠다. 배경 클릭은 다 펼쳤을 때만 지도를 접는다(펼치거나 접는 중의 클릭은 무시한다)
- 만남 대화 입력칸에 쓰는 동안에도 캐릭터 조작을 끈다 — 글자를 칠 때 캐릭터가 움직이지 않는다

### 내 주변 (`/nearby`)

- 내 위치에서 시작한다. 씬이 열리면 곧바로 위치를 요청하고, 받을 때까지 대기 화면에서 기다린다 — 시간 제한이 없고, 정해 둔 기본 좌표로 시작하지 않는다
- ±50m 안 위치가 오면 바로 시작하고, 그보다 흐리면(와이파이·IP 추정 포함) 첫 위치를 받고 6초 동안 더 나아지길 기다렸다가 그 사이 가장 나은 위치로 이 근처에서 시작한다
- 위치를 하나도 못 받는 동안(권한 창·찾는 중·권한 거부·https 아님·미지원)은 스스로 넘어가지 않는다. 대기 화면은 상태별 제목·안내를 보여 주고, 권한 거부면 "다시 시도"(iOS 사파리는 "새로고침") 버튼을 띄운다
- PC는 시작한 자리에서 플레이 씬과 같은 조작·관성·카메라로 걷는다(1m = 1m). GPS를 따라가지 않아, 흐린 위치로 시작했어도 나중에 옮기지 않는다. 바닥이 평평해 충돌은 끝없는 평면 하나다
- 모바일은 실제 GPS 위치까지 걸어간다 — ±50m 안 위치만 걸음 목표로 쓰고(그보다 흐리면 멈춰 둔다), 1.5m 안이면 서고, 그보다 4m 더 멀면 최고 속도다. GPS가 한 번에 150m 넘게 튀면(지하철·차) 걸어가지 않고 곧장 옮긴다
- 휴대폰에서 GPS가 걸음을 따라가지 못할 때(멈춤·흐림), 위치를 받을 수 없게 됐을 때는 위쪽에 알림 한 줄과 "지도 보기" 버튼을 띄운다(지도가 펼쳐져 있으면 숨긴다)
- 우상단 지도 버튼이나 M 키로 펼침 지도를 펼치고 접으며, Esc는 접기만 한다(소리가 없어 Ctrl+M은 없다). 지도가 화면에 있는 동안(접을 때는 배경이 다 걷힐 때까지) 직접 조작(키보드·마우스·터치·게임패드)은 끄고, 휴대폰 GPS 걷기는 계속된다
- 걷는 만큼 앞쪽 바닥을 이어 깔아 끝이 없다

### 맵 (`/map`, 예정)

- PC는 WASD·방향키로 이동하고(남북 3m/s, 동서 약 2.4m/s — 같은 도/초를 경도·위도에 더한다), 모바일은 실제 GPS 위치로 이동한다
- 새 위치는 15m 이내 도로 선분에 스냅한다
- 쿼터뷰 고정 카메라가 이동할 때마다 지도 중심을 캐릭터로 맞춘다
- "내 위치로" 버튼은 GPS를 다시 조회해 그 위치로 이동한다

### 속도 검증 (맵)

- 서버: 모든 `move` 패킷을 시속 30km 기준으로 검증해 초과분을 버린다 (2차 방어)
- **(예정)** 클라이언트: 직전 위경도와 비교해 시속 30km를 넘는 이동은 전송하지 않고, 0.3m 미만 이동은 전송을 생략한다 (1차 방어)
- **(예정)** 다른 유저 캐릭터는 수신 좌표로 부드럽게 보간해 움직인다

### 이동 제한 (예정)

- 무료 유저는 스폰 기준점에서 반경 1km 이내로 이동을 제한하고, 가시거리 라이선스 구매 시 해제한다
- 경계 도달 시 화면 중앙에 "이동 제한 반경 도달" 알림 페이드인
- 이상 패턴 감지 시 해당 유저 씬 렌더링 10분 동결

## 4. B2B 광고 규칙

### CPT(기간 고정제) 모델 고정

- CPC(클릭당 과금) / CPA(행동당 과금) 정산 방식 완전 배제
- 기간 고정 정가 구좌 판매만 허용 (예: 특정 랜드마크 1개월 독점 = 정가)

### 광고 자동화 스케줄러

- `pg_cron`이 매일 00:00 KST(15:00 UTC)에 `starts_at`이 오늘인 구좌를 활성화하고, `ends_at`이 어제인 구좌를 비활성화한다(`is_active`)
- 구좌마다 비활성 기간에 쓸 기본 텍스처(`default_texture_url`)를 둔다
- **(예정, Phase 4)** 비활성 구좌를 브랜드 텍스처 대신 기본 텍스처로 씬에 표시

### 유효 노출 카운팅 (예정, Phase 4)

- 씬 뷰포트 안에 스폰서 랜드마크 바운딩 박스가 **1초 이상 완전히 진입**했을 때만 `ad_impressions`에 기록
- 0.1초 미만 스쳐 지나간 경우 카운팅 제외

### 광고 형태 제한

- 3D 공간 내 로우폴리 입체 간판·랜드마크 표면 그래픽 + 펼침 지도 좌표 마커만 허용
- 2D 웹 팝업 배너·텍스트 팝업 전면 금지
- 랜드마크 클릭 시 팝업 호출 금지
- **(예정, Phase 4)** 랜드마크 클릭에는 캐릭터 절레절레 No-Action 애니메이션으로 대응

## 5. 멀티플레이어 규칙

플레이 씬과 내 주변(베타)은 로그인 없는 익명 멀티플레이다. 플레이 씬에서는 가까이 마주친 두 사람이 서로 받아들여 1:1 만남 대화를 나누고, 섹터 채팅은 맵(예정)에 적용한다.

### 플레이 씬 익명 멀티플레이

- 로그인 없이 방을 배정받는다. 방은 20명까지 먼저 연 방부터 채우고, 다시 접속하면 전에 있던 방으로 돌아간다(자리가 있을 때)
- 다른 캐릭터의 위치·방향·모션(기본·공중·심심함)·피부/옷 색이 원본처럼 보간되어 보인다. 이름표·충돌은 없고, 같은 방 사람과는 만남 대화를 나눈다(아래)
- 오디오·잔디 반응은 내 캐릭터만 대상으로 한다
- 5분 동안 움직이지 않으면 방에서 빠지고(다른 사람 화면에서 사라진다), 다시 움직이거나 탭으로 돌아오면 들어간다. 만남 대화가 오가는 동안은 움직이지 않아도 빠지지 않는다. 탭을 숨겨도(창 최소화·다른 탭) 방에 남아 다른 사람에게 계속 보인다
- 서버에 닿지 못하거나 정원이 차면 혼자인 채로 씬이 그대로 돌고, 뒤에서 다시 접속을 시도한다
- 비정상 이동(초당 10m 초과, 5초 안의 두 번째 순간이동)은 서버가 버리고, 초당 60건을 넘게 보내는 연결은 끊는다

### 만남 대화 (플레이 씬)

수치는 `shared/relay/contract.ts`의 `TALK` 하나에 두고, 성사·종료는 서버가 판정한다.

- **말 걸기 버튼**: 20m 안에 2초 머문 사람 가운데 화면에 보이는 가장 가까운 사람 머리 위에 뜨고, 30m 밖으로 멀어져야 사라진다(경계에서 깜빡이지 않게). 등 뒤라 화면에 없는 사람에게는 뜨지 않고 E 키로도 걸리지 않는다. 대화 중이거나 요청을 걸어 두었거나 받은 요청이 떠 있는 동안에는 뜨지 않는다
- **요청**: 같은 방 30m 안 사람에게만 걸린다. 한 사람은 한 번에 요청 하나만 걸고 하나만 받는다 — 대화 중이거나 다른 요청을 받고 있는 사람에게 건 요청은 이어지지 않는다. 요청은 15초 뒤 사라지고, 1분에 6번까지 걸 수 있다. 두 사람이 서로 걸면 곧바로 열린다
- **이어지지 않은 요청**: 거절·15초 시간 초과·상대가 바쁨을 건 사람에게 같은 한 줄("지금은 바쁜가 봐요")로만 알린다. 그 사람에게는 5분 동안 다시 걸 수 없다(거절·시간 초과면 서버도 같은 5분 동안 그 방향의 요청을 막는다). 받은 사람은 거꾸로 말을 걸 수 있다
- **받기 끄기·가리기**: 우상단 말 걸기 받기 버튼을 끄면 오는 요청을 카드 없이 거절한다(브라우저 `localStorage`에 기억하고, 내가 거는 것은 그대로 된다). '이 사람 가리기'는 그 사람의 버튼·요청·말풍선을 이번 방문 동안 숨기고 대화 중이면 끝낸다
- **대화**: 두 사람만 본다. 한 번에 200자까지, 0.5초에 한 번까지 보낸다. 링크(`http`·`www.`·흔한 도메인)가 든 글은 보내지 않고, 제어 문자는 서버가 공백으로 바꾼다. 보낸 글은 대화 창에 최근 60줄까지 남고, 두 사람 머리 위 말풍선으로 7초 동안 보인다
- **끝**: ×(상대에게는 "상대가 대화를 마쳤어요"), 30m 넘게 10초 멀어짐(멀어지는 동안 대화 창 제목이 "멀어지고 있어요"로 바뀐다), 3분 동안 글 없음, 상대 연결 끊김으로 끝나고 끝난 까닭을 위쪽 한 줄로 알린다. 내 연결이 끊겨도 대화는 끝난다
- **저장 없음**: 서버는 대화 글을 받은 즉시 두 사람에게만 보내고 저장·기록하지 않는다. 이름·기기 정보는 싣지 않는다
- **남용 방지**: 대화 이벤트도 상태 메시지와 같은 초당 60건 한도로 세고, 넘으면 연결을 끊는다
- **시험 단계**: 로그인 없는 익명 대화는 공개 출시 전 시험용이다. 공개 출시 전에 로그인·신고·차단·이용 연령을 갖추고 대화 저장 여부를 정한다(랜덤 채팅 관련 규정 검토)

### 내 주변 익명 멀티플레이

- 같은 동네에 들른 사람의 캐릭터가 **실제 자리**에 보인다 — 내 실제 위치가 가까운 사람에게 보이는 것이 이 기능의 목적이다. 휴대폰은 GPS를 따라 걸으므로 지금 있는 자리가, PC는 시작한 자리에서 키보드로 걸어간 자리가 보인다. 로그인·이름·채팅은 없다
- 방은 없다. 반경 200m 안에서 가까운 19명까지 보인다(나 포함 20명). 보이던 사람은 230m까지 멀어져도 남아 경계에서 깜빡이지 않는다
- 멀어지면 사라지고(0.25초), 다시 다가오면 나타난다(0.35초). 5분 무변화·탭 숨김(방에 남는다)·서버 연결 실패·비정상 이동 처리는 플레이 씬과 같다
- 서버는 위치를 메모리에만 들고 저장하지 않는다

### 섹터 채팅 규칙 (맵)

- 모든 채팅 메시지는 DB 영구 저장 금지 (무상태 휘발성) — 서버(`/sector` 게이트웨이)가 받은 즉시 섹터 단위로 방송한다
- 메시지는 200자, 닉네임은 32자까지만 받는다
- **(예정)** 채팅 입력 UI, 말풍선 + 채팅 로그 7초 후 자동 페이드아웃, 도배 방지 0.5초 발송 디바운스 락

### 안전 규칙 (예정)

- 앱 구동 시 화면 주시 위험 경고 팝업 3초 강제 노출 (면책 팝업, Phase 5 법적 검토)
- 심야 시간대(23:00~05:00) 실외 GPS 위치 표시 자동 잠금
