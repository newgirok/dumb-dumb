# 용어 사전

프로젝트에서 사용하는 도메인 용어 정의.

---

## 게임/서비스 용어

| 용어 | 정의 |
|---|---|
| **선택 페이지 (Route Chooser)** | 루트(`/`) 페이지이자 공개 진입점(`app/page.tsx`). 여름 오후 풍경 위에 제목 "Dumb Dumb"을 둔 게임 타이틀 화면으로, 목적지 버튼 3개(플레이 `/play` · 내 주변 `/nearby` 베타 · 에셋 미리보기 `/asset-viewer` 개발용)를 세로로 쌓아 둔다. 세 경로는 `lib/routes.ts`의 `SCENE_ROUTES`다. |
| **플레이 씬 (Play Scene)** | `/play`에서 로그인 없이 공개되는 3D 씬(`features/play`). 베이크드 로우폴리 지오메트리를 씬 전용 단일 Three.js 캔버스에 그리며, 좌표계는 씬 로컬 미터 좌표다. 같은 방 다른 방문자의 캐릭터가 익명 소켓으로 함께 보이고, 가까이 마주친 사람과는 만남 대화를 나눈다. |
| **내 주변 (Nearby)** | 유저의 실제 위치 주변 길(OpenStreetMap)을 플레이 씬 화풍으로 깐 3D 공간(`/nearby`, 1단계 베타). 좌표는 GPS 위치를 격자에 맞춘 원점 기준 미터(1m = 1m)다. 위치를 받을 때까지 기다렸다가 시작하고(대기형 시작), 펼침 지도에는 캐릭터 자리와 화면이 보는 방향이 '나'로 보인다. 반경 200m 안 가까운 19명의 캐릭터가 실제 자리에 보인다(방 없음). |
| **에셋 미리보기 (Asset Viewer)** | `/asset-viewer`의 개발용 페이지(`features/asset-viewer/`)로, 선택 페이지의 에셋 미리보기 버튼으로 연다. ref-assets 캐릭터·소품을 지도 없이 띄워 크기·본·애니메이션·인스턴스·LOD 규격을 확인하고, 세로로 긴 화면에서는 반응형 구도와 같은 기준으로 화각을 넓힌다. |
| **방 (Room)** | 플레이 씬 익명 멀티플레이의 중계 단위. 최대 20명이며 서버가 먼저 연 방부터 채운다. 같은 방 사람끼리만 서로의 캐릭터가 보이고 만남 대화를 나눈다. 내 주변에는 방이 없고 사람마다 가까운 사람을 고른다. |
| **만남 대화 (Encounter Talk)** | 플레이 씬에서 가까이 마주친 두 사람이 서로 받아들여 여는 1:1 글 대화. 화면에 보이는 상대 캐릭터를 누르면 그 사람 둘레에 **원형 메뉴**가 펼쳐지고, 4m 안(평소 목소리로 대화가 들리는 거리)이면 켜지는 말 걸기 아이콘(말풍선)으로 건다(4m 안에 들어온 보이는 사람마다 머리 위에 누를 수 있다는 손가락 표시가 바로 뜨고 PC는 E 키로 가장 가까운 사람에게 바로 건다). 걸면 상대 화면에 15초짜리 요청 카드가 뜬다. 상대가 받아들이면 두 사람만 보는 대화 창과 머리 위 말풍선(7초)으로 글을 주고받고, ×·10m 넘게 10초 멀어짐·3분 동안 말 없음·상대가 떠남으로 끝난다. 거절·시간 초과 뒤 5분 동안 그 사람에게 다시 걸 수 없다. 글은 저장하지 않는다. 화면은 `components/hud/talk-layer.tsx`, 상태는 `lib/realtime/talk.ts`, 판정은 실시간 서버 `apps/realtime/src/relay/talk.ts`이고, 방 중계(`/room`) 연결로 `talk*` 이벤트를 주고받는다. |
| **말 걸기 받기 (Talk Requests)** | 플레이 씬 우상단 네 번째 버튼. 끄면 오는 만남 대화 요청을 카드 없이 거절하고(내가 거는 것은 그대로 된다), 설정은 브라우저 `localStorage`(`dumb.talk.open`)에 남는다. 한 사람의 요청만 거절하려면 요청 카드의 '다음에'를 누른다 — 그 사람은 5분 동안 다시 걸 수 없다. |
| **맵 (Map)** | `/map`에 만들 로그인 유저용 멀티플레이 화면(예정). Mapbox GL Standard 실지형 지도 위에 Three.js 캐릭터를 커스텀 레이어로 얹고, 좌표계는 위경도(EPSG:4326)다. |
| **반려인 (Owner)** | 내 캐릭터. 반려동물을 목줄로 데리고 걷는 사람이다. 첫 기본 모습은 아이이고, 앞으로 아이부터 어른까지 여러 모습의 에셋 중에서 고른다(로드맵 P2-5). 보호자는 미성년 이용자의 법정대리인을 부를 때 쓴다. |
| **반려동물 (Pet)** | 반려인이 목줄로 데리고 다니는 동물. 반려인 곁에서 걸음을 맞춰 따라오고, 목줄이 반려인 손과 반려동물 목을 잇는다. 강아지·고양이부터 목장·숲·야생 동물까지 종이 다양하고, 앞으로 여러 종의 에셋 중에서 고른다(로드맵 P2-5). |
| **3인칭 추적 카메라 (Third-Person Camera)** | 플레이 씬과 내 주변의 메인 카메라. 시선 목표점(발 위 1.1m) 중심 반경 5.836m·앙각 9.866°에서 캐릭터를 뒤따르고, 세로로 긴 화면에서는 반응형 구도로 화각을 넓힌다. |
| **쿼터뷰 고정 카메라 (Quarter-View Camera)** | 맵(예정)의 Mapbox 카메라. pitch 45°·bearing 45°를 고정하고 이동할 때마다 지도 중심을 캐릭터로 맞추며, 줌(14~20)만 허용한다. |
| **펼침 지도 (Paper Map)** | 플레이 씬과 내 주변에서 우상단 지도 버튼이나 M 키로 펼치는 종이 지도(`components/map/paper-map.tsx`, 스타일 `paper-map-style.ts`). 씬 렌더러와 분리된 독립 Mapbox GL 캔버스이고, 접힌 종이가 옆으로 펼쳐진다(종이 폭 720px 이상 3단, 440px 이상 반 접기, 그보다 좁으면 접지 않고 바로 펼침). 북쪽이 위인 평면 지도에 플레이 씬은 유저의 실제 GPS 위치를, 내 주변은 캐릭터 자리와 화면이 보는 방향을 '나'로 표시하는 보조 뷰다. 끌기·확대/축소는 되고 회전·기울이기는 막으며, M·Esc·×·배경 클릭으로 접는다. |
| **로우폴리 (Low-Poly)** | 각지고 간결한 폴리곤으로 구성된 3D 스타일. 플레이 씬·내 주변 에셋과 캐릭터 전체에 적용. |
| **가시거리 안개 (Fog of War)** | 캐릭터 중심에서 가시거리 반경 바깥을 가리는 메카닉. 탐험 긴장감과 BM을 연동하는 핵심 요소이며, 씬 렌더링 적용은 Phase 4에서 진행한다. |
| **가시거리 라이선스** | 유저별 가시거리 반경(`user_licenses.visibility_radius_m`, 기본 25m)을 영구적으로 확장하는 기능 라이선스. 아바타 외형과 완전히 독립된 별도 상품. |
| **이동 조작** | 플레이 씬은 PC WASD·방향키·마우스 가상 조이스틱·게임패드, 모바일 터치 조이스틱(누른 자리 기준, 탭하면 점프)으로 움직인다. 내 주변은 PC에서 플레이 씬과 같고, 모바일에서는 직접 조작 없이 ±50m 안 GPS 위치(흔들림을 거른 자리, 차도 위면 가장 가까운 인도)까지 걸어간다. 펼침 지도가 화면에 있는 동안(접을 때는 배경이 다 걷힐 때까지)은 직접 조작이 꺼진다. 맵(예정)은 PC WASD·방향키, 모바일 실제 GPS로 움직인다. |
| **GPS 위치** | 플레이 씬에서는 펼침 지도의 '나' 표시에만 쓰인다(사이트 권한이 이미 허용돼 있으면 씬을 열 때, 아니면 지도를 처음 펼칠 때 찾기 시작한다). 내 주변에서는 시작 위치를 정하고(대기형 시작), 모바일에서는 ±50m 안 위치일 때만 흔들림을 걸러 캐릭터를 그 자리까지 끌고 간다. 맵(예정)에서는 시작 위치를 정하고, 모바일에서는 캐릭터 이동을 직접 구동한다. 씬과 펼침 지도는 `lib/geo/gps.ts`의 추적기(`watchPosition` 하나)를 나눠 쓰고, 위치는 보안 연결(https 또는 localhost)에서만 받는다. |
| **GPS 상태 (GPS Status)** | `lib/geo/gps.ts`의 추적기가 권한·오류·정확도를 묶어 내는 상태 하나. `idle`·`unsupported`(위치 기능 없음)·`insecure`(https 아님)·`prompt`(권한 창 대기)·`searching`(찾는 중)·`unavailable`(위치 없음, 계속 찾는다)·`denied`(사이트 차단 또는 기기 위치 꺼짐)·`good`(±20m 안)·`fair`(±50m)·`weak`(±150m)·`coarse`(±1km)·`approximate`(1km 넘음)·`stale`(받다가 멈춤)이 있고, 첫 위치가 8초 넘게 오지 않거나 시간 초과가 나면 `slow`가 켜진다. 상태별 안내 문구는 `lib/geo/gps-messages.ts`가 기기(iOS·Android·Windows·Mac, 삼성 인터넷, 앱 속 브라우저)에 맞춰 고르고, 펼침 지도의 쪽지·도장·정확도 원·음파, 지도 버튼 구석 점(`GpsBadge`), 내 주변 대기 화면과 위쪽 알림이 이 상태를 보여 준다. |
| **대기형 시작 (Start Wait)** | 내 주변이 시작 위치를 정하는 방식(`lib/geo/gps.ts`의 `waitForStartFix`). ±50m 안 위치가 오면 바로 시작하고, 그보다 흐리면 첫 위치를 받고 6초 동안 더 나아지길 기다렸다가 그 사이 가장 나은 위치로 이 근처에서 시작한다. 위치를 하나도 못 받는 동안(권한 창·찾는 중·권한 거부·https 아님·미지원)은 시간 제한 없이 대기 화면에서 기다린다. |
| **도로 스냅 (Road Snap)** | 맵(예정)에서 새 위치를 15m 이내 Mapbox `road` 레이어 선분의 최근접점으로 보정하는 처리. |
| **걸을 수 있는 곳 (Walkable)** | 내 주변 바닥에서 화면에 그린 막힌 곳을 뺀 모든 곳 — 잔디·공터·광장·인도·보행로. 지금 막힌 곳은 차도이고, 건물·물은 그리게 되면 막힌 곳이 된다. 캐릭터는 시작 자리와 휴대폰 걸음 목표가 차도 위면 거리와 상관없이 가장 가까운 인도(그 가운데)로 옮기고, 그 밖에서는 GPS 자리 그대로 선다. |
| **랜드마크 (Landmark)** | 씬에 배치해 브랜드 텍스처를 입히는 B2B 스폰서십 대상 오브젝트. 좌표는 `sponsor_buildings.geom`에 두고, 씬 배치와 펼침 지도 좌표 마커는 Phase 4에서 붙인다. |
| **섹터 (Sector)** | 맵의 실시간 브로드캐스트 단위(실시간 서버 `/sector` 게이트웨이). 위경도를 500m × 500m 격자로 나누며(위도별 경도 폭), 섹터마다 socket.io 룸이 있다. 서버가 섹터 단위로 위치를 묶어 방송한다. |
| **Pre-Join** | 섹터 경계 50m 이내에서 인접 섹터 socket.io 룸을 함께 구독하여 경계 이동 시 끊김 방지. |

## 기술 용어

| 용어 | 정의 |
|---|---|
| **WebGL 컨텍스트 구성** | 플레이 씬과 내 주변은 씬 렌더러와 펼침 지도 Mapbox 캔버스를 서로 다른 WebGL 컨텍스트로 분리해 씬 성능을 우선한다. 맵(예정)은 Three.js 렌더러가 Mapbox 캔버스의 WebGL 컨텍스트를 공유(Context Sharing)해 커스텀 레이어로 그린다. |
| **반응형 구도 (Responsive Framing)** | 3인칭 추적 카메라가 화면 비율에 맞춰 구도를 잡는 기법(`lib/three/third-person.ts`의 `framingFor(aspect)`). 16:9 이상은 세로 화각 45°·반경 5.836m·앙각 9.866° 구도를 그대로 쓰고, 9:19.5로 좁아질수록 매끄럽게(smoothstep) 세로 화각을 66°까지 넓히고 반경을 1.3배까지 늘리고 앙각을 8°까지 더 올리고 시선을 5°까지 들어, 가장 긴 세로 화면에서 하늘·앞길·발밑이 대략 3분의 1씩 보이게 한다. 창 크기·회전으로 비율이 달라지면 부드럽게 따라가고, 마우스 조이스틱 고정점도 구도에 맞춰 캐릭터 발끝을 따라간다. 플레이 씬·내 주변은 같은 컨트롤러라 똑같이 적용되고, 에셋 미리보기도 같은 기준으로 화각을 넓힌다. |
| **GiST 인덱스 (Generalized Search Tree)** | PostGIS 공간 데이터에 적용하는 R-Tree 기반 인덱스. `sponsor_buildings.geom`(geometry)에 걸려 있다. 조회 함수 `nearby_sponsor_buildings`는 `geom::geography` 식으로 조회해 이 인덱스와 식이 달라, 인덱스를 태우려면 geography 표현식 인덱스가 필요하다(Phase 4). |
| **멱등성 키 (Idempotency Key)** | 결제 시 생성하는 주문 UUID. PG사 웹훅이 중복 수신되어도 동일 키를 기준으로 단 1회만 처리되도록 보장. |
| **appearance_hash** | 아바타 외형 파라미터(피부·헤어·헤어 색·상의·상의 색·하의·하의 색·신발·액세서리)와 난수 `seed`를 합쳐 SHA-256으로 해싱한 값. DB UNIQUE 제약이 같은 해시의 중복 발급을 막는다. seed가 해시에 들어가므로 팔레트 조합이 같아도 seed가 다르면 발급된다. |
| **Prune / Culling** | 맵(예정)에서 50m 이동마다 캐릭터 반경 450m 밖의 피어 오브젝트를 씬에서 빼고, 공유되지 않는 지오메트리와 재질을 해제하는 GC 작업. |
| **관심 영역 관리 (Interest Management)** | 실시간 서버가 누구의 상태를 누구에게 보낼지 고르는 일. 네임스페이스는 고르는 방식으로 부른다 — 방 중계 `/room`(정원 20명 방, 플레이 씬), 근접 중계 `/proximity`(반경 200m 가까운 19명, 내 주변), 섹터 중계 `/sector`(500m 격자 칸, 맵) ([ADR 008](../adr/008-interest-management-naming.md)). |
| **CPT (Cost Per Time)** | 기간 고정제 광고 과금 방식. 클릭·행동 기반(CPC/CPA) 대신 "특정 랜드마크 1개월 독점"처럼 기간 단위 정가 판매. |
